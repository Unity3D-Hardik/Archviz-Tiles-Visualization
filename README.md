# Archviz Tiles Visualization (Unity)

An interactive, real-time Architectural Visualization (Archviz) application built in Unity, designed to showcase, customize, and visualize different tile designs, materials, and layouts in high-fidelity 3D environments.

This project focuses on providing a seamless user experience for interior designers, architects, and clients to experiment with flooring and wall tile configurations before implementation.

---

## 🚀 Features

* **Real-Time Material Swapping:** Dynamically change tile textures, colors, glossiness, and roughness.
* **Dynamic Tiling & Scaling:** Adjust UV tiling directly through the UI to change tile sizes (e.g., 60x60, 30x60) dynamically.
* **Procedural Grout Customization:** Change grout width and color to match different architectural styles.
* **High-Fidelity Rendering:** Utilizes Unity's Universal Render Pipeline (URP) / High Definition Render Pipeline (HDRP) for realistic lighting, reflections, and shadows.
* **Interactive UI:** Intuitive runtime user interface for picking tiles, adjusting parameters, and switching camera angles.
* **Multiple Layout Patterns:** Support for different tiling patterns (e.g., Grid, Brick, Herringbone).

---
